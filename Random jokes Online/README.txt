# Random Joke Generator

A simple web application that displays random jokes using an external API.

## Features

- Fetch random jokes from API
- Display joke on button click
- Uses XMLHttpRequest for API calls
- Simple and clean UI
- Instant joke refresh

## Technologies Used

- HTML5
- CSS3
- JavaScript
- XMLHttpRequest (AJAX)

## Skills Demonstrated

- API Integration
- AJAX requests (XMLHttpRequest)
- DOM Manipulation
- Event Handling
- Asynchronous Programming basics

## Purpose

This project was created to practice working with APIs and improve JavaScript skills.
